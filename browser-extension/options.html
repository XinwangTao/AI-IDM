AI-IDM 下载接管

把浏览器下载交给本地 AI-IDM 多连接下载器（下载器同时可被 AI 通过 MCP 调用）

连接本地服务

令牌在首次启动服务时自动生成，保存在 config.json 的 server_token。

启动服务

  1. 安装下载器：pip install ai-idm（或在本仓库直接 pip install -e .）
  2. 启动接管服务：ai-idm serve —— 它会打印地址、令牌和面板链接
  3. 把令牌填到上面，点「测试连接」
  4. 之后浏览器里点下载，文件会自动落到 ~/Downloads（可用 ai-idm serve -d 目录 改）
扩展源码在仓库的 browser-extension/ 目录（用 pip 安装的话从 github.com/XinwangTao/AI-IDM 下载该目录即可）。让服务开机自启：把 ai-idm serve 做成计划任务/快捷方式；也可 ai-idm serve --no-run 只接计入队，再用 ai-idm queue run 消费。
