  • Q1 轮询频率：页面/后台 0.5s、弹窗 0.8s，都是回环请求（/status 读内存+SQLite，开销很小）。接受吗？

确认结论（2026-10-22）

  • Q1：页面/后台轮询 0.5s、弹窗 0.8s。
  • Q2：单活跃任务徽标显示百分比数字，≥2 个显示数量。
  • Q3：「已交回浏览器」卡片 6s 后消失，系统通知不变。
