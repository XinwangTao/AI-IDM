批次范围

  • 动机：① 回环豁免硬编码 127.0.0.1:13391 / localhost:13391（background.js:19）——服务一旦改端口（如 13392），本机服务/面板触发的下载会被扩展接管，形成取消-重交的回环风险；② SKIP_PATTERNS 只覆盖 Chrome/商店更新域名，Edge 用户浏览器自身更新包（.crx/ms-download）会被误接管。
  • In：background.js — 回环豁免放宽为任意端口（解析 URL hostname ∈ 127.0.0.1 / localhost / [::1] / ::1；解析失败退回字符串包含匹配）；SKIP_PATTERNS 补 Edge 更新域名 3 条。
  • Out：content.js / server / engine；手动模式与右键/弹窗入口（不经过本门禁）；取消/erase 时序参数；接管后的跟踪流程（已有图）。

设计取舍（待确认点）

  • 回环任意端口全跳过：代价是本机自建站点（如 localhost:8080）的下载也不再接管——多连接对同机下载没有收益，且服务自身经回环触发的下载（改端口场景）必须豁免，权衡后建议全跳。
  • Edge 域名取实测三类：edge.microsoft.com / msedge.api.cdp.microsoft.com / msedge.b.tlu.dl.delivery.mp.microsoft.com。有实际遇到的其它域名再补。
  • 只动判定不动时序：cancel/erase 的 900ms/600ms 是踩过坑调出来的，本批不碰。
